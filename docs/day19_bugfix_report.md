## Отдельно о Git

В ZIP есть неиспользуемая вложенная папка `biblioteka-online-projekt`,
которая записана в Git как **gitlink / submodule mode 160000**. Перед удалением
ссылки из Git убедитесь, что папка действительно пуста/не нужна.
Папка `.git` не включена в исправленный архив намеренно: ваш исходный Git
с незафиксированными и частично подготовленными изменениями сохраняйте отдельно.
